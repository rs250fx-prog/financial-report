# note 用の簡易版

note.com へ手動でコピペするための原稿を置く。**ビルドには含まれない**
（`src/content/` の外なので Astro は読まない）。

## サムネイル

`thumb_YYYYMMDD.png`（1280×670）。`node tools/make-thumb.mjs YYYY-MM-DD` が、
日次レポートの frontmatter から書き出す。週次は `node tools/make-thumb.mjs YYYY-wNN` で
`thumb_YYYYwNN.png`（ラベルが「マネーフロー・ウィークリー」になり、日付の位置に対象期間が入る）。手で作らない。文言を直したいときは
原稿の `thumb` を直して再実行する。

`market_dashboard_YYYYMMDD.svg` は、サムネイルを手作業で組んでいた頃の数値5枠
（〜10/2号）。いまは `make-thumb.mjs` が同じ枠を描く。

## 位置づけ

note を入口にして、サイトへ送客するための簡易版。full版は
`src/content/reports/YYYY-MM-DD.md`。

## 線引き

**note に出す**
- 結論（今日の資金フロー）
- スナップショットの数字
- その日の論点を2つまで
- Market Bias と監視項目

**サイトに残す**
- 金利の多層（米2年・日本10年・実質金利）
- ゴールドの三軸とテクニカル・レベルの全段
- Crypto / Volatility
- Next Flow のシナリオA/B/C
- 出典リンク

読み応えのないティーザーにしない。**数字と結論は出し切り、
分解の過程をサイトに残す**という切り方にする。そうしないと
note 側が「読む価値がない」と判断されて送客が成立しない。

## note 側の書式制約

- 表（table）を使わない
- すみつき括弧を使わない
- 見出しは `##` / `###`、区切りは `---`
- 資金移動は「→」で表す
- 末尾にハッシュタグ

## 免責

金融商品取引法上、個別の売買推奨はできない。簡易版にも免責を必ず入れる。
