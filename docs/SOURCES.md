# 指標の取得元

**この文書が指標の唯一の基準である。**毎日同じ指標を同じ形式で記録することを掲げている以上、
**取得元が日によって変わると、並べた数字が比較できなくなる。**

公開版は `/sources/` にある。読者が数字を検証できる状態にしておくのが編集方針であり、
この文書はその原本である。片方だけ直さない。

---

## 1. 原則

- **系列を1つに固定する。**同じ指標を日によって別の出所から取らない
- **値には必ず「いつ時点か」を添える。**日付の無い数字は検証できない
- **取れなければ「未確認」と書く。**近い数字で埋めない
- 出所が食い違ったら、**日付と具体性のあるほうを採る。**それでも決まらなければ両方を併記して未確認とする

過去に実際、同じ日の金の終値が4つの出所で 4,290 / 4,304 / 4,314 / 4,318 と割れた。
前号と同じ系列（usagold）を採ることで決着させている。**水準そのものより、
同じものさしで測り続けることのほうが、この媒体では重い。**

---

## 2. FRED から取るもの

鍵もアカウントも要らない。`python tools/fetch-indicators.py` で一括取得できる。

| 指標 | 系列ID | 反映の遅れ |
|---|---|---|
| 実質金利（TIPS10年） | `DFII10` | 2営業日 |
| VIX | `VIXCLS` | 1営業日 |
| 米10年債利回り | `DGS10` | 2営業日 |
| 米30年債利回り | `DGS30` | 2営業日 |
| 米2年債利回り | `DGS2` | 2営業日 |
| S&P 500 | `SP500` | 1営業日 |
| 期待インフレ率（10年BEI） | `T10YIE` | 2営業日 |

### 遅れの扱い

**遅れを理由に空欄にしない。**「9/28時点」と添えて載せる。翌号で確定値に差し替える。

実質金利が9本中7本で「未確認」のまま残っていたのは、**探し方が違ったため**である。
報道記事はこの指標を「今日の値」として書かないので、ニュース検索では出てこない。
FREDには毎営業日の確定値がある。

### 注意

CSVはキャッシュされる。素で叩くと最新1日分が落ちた結果が返ることがあり、
「まだ出ていない」と誤認する。実際にVIXで1日ずれた。取得ツールは毎回違うクエリを付けている。

## 3. FRED では間に合わないもの

| 指標 | 取得元 | 理由 |
|---|---|---|
| 金（XAU/USD） | [USAGOLD 日次レポート](https://www.usagold.com/daily-precious-metals-market-report/) | 出所により28ドル幅で割れる。**前号と同じ系列を採る** |
| WTI・Brent原油 | 当日の報道（CNBC・Investrade等） | FRED `DCOILWTICO` は約1週間遅れ。**確定値の裏取りにのみ使う** |
| ドル指数 DXY | 当日の報道（FXStreet等） | ICEの指数のためFREDに無い。`DTWEXBGS` は**広義ドル指数で別物。代用しない** |
| 日経225 | [日経公式](https://www.nikkei.com/marketdata/quote/NK225/) | |
| BTC | [CoinDesk](https://www.coindesk.com/) | |
| 日経VI | 大阪取引所・日経 | |

報道から取る指標は、**必ず複数の記事で突き合わせる。**1社だけを信用しない。
過去に、ある価格サイトが金2,048ドル・DXY 103.45という、他のどの出所とも矛盾する値を返した。

---

## 4. 使い方

```bash
python tools/fetch-indicators.py
```

出力をそのまま本文に転記できる形にしてある。日付を落とさないこと。

```
実質金利（TIPS10年）：2.90%（9/28時点、FRED DFII10）
```
